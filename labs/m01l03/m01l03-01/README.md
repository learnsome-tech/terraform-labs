## Goal

You can install Terraform, confirm the version you are running, and use the two commands that cost nothing and catch most mistakes: format and validate.

In the lesson: Terraform is a single compiled binary with no runtime behind it, which makes installing it unusually dull. There are three routes. Your system package manager is the easiest, and it is what you should use today. A version manager is what you will want later, because different projects pin different versions and you will eventually need two at once on the same machine. And you can always download the zip file, unpack it, and put the one binary somewhere on your path, which is worth knowing because that is all the other two are doing for you. Whichever you choose, the check afterwards is the same, and it is the next screen.
