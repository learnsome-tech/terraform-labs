## Check yourself

- Name the four things a good variable declaration includes.
- Which wins, a value in terraform dot tfvars or one in an environment variable?
- When does Terraform stop and ask you for a value, and when does it fail instead?
- What does a validation block do, and when does it run?
- What does marking a variable sensitive protect, and what does it not protect?
