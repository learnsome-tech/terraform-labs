## Check yourself

- Which three things does a plan compare?
- What does the tilde mean, and how does it differ from the pair joined by a slash?
- Why does a plan show some values as known after apply?
- What does applying a saved plan file protect you from?
- Give two reasons an apply can fail even though the plan was correct.
