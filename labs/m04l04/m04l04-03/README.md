## Goal

You can evaluate a public registry module by source address, documentation, inputs, outputs, and ownership risk.

In the lesson: A version constraint is a change control tool. A narrow constraint reduces surprise, while a lock file records the exact package selected. Upgrade deliberately: read release notes, refresh a branch, inspect the plan, run tests, and let a reviewer compare the diff. Do not float a public module to the newest release in an unattended pipeline. Reproducibility is a feature you have to choose.
